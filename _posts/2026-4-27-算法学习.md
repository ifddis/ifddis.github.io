## 📝 题目描述
> 用自己的话简要描述题目（不要直接复制原题）
给出两个有序数组，数组一末端是数组二长度那么多的0，将数组二合并进数组一，使之依旧有序
---

## 💡 思路分析
- 核心思路：1、简单拷贝数组2进数组1，然后排序
- 法2：（优化）：正难则反，每次从两个数组末端取数，按从大到小插入到数组1的末端，显然这样是可以避免覆盖的。
- 关键难点：
- 是否参考题解：（是）

---

## 🔍 解法拆解
### 方法二（推荐）
- 时间复杂度：O(M+N)
- 空间复杂度：O（M+N）
- 关键步骤：
  1. 定义三个指针p、p1、p2，分别指向数组1尾端，数组1非0部分尾端，数组2尾端
  2. 从数组1尾端开始遍历（也就是p），若p1还未遍历完，则说明还可以继续插入数组2的元素

---

## 🧾 代码实现

```Python
class Solution(object):
    def merge(self, nums1, m, nums2, n):
        """
        :type nums1: List[int]
        :type m: int
        :type nums2: List[int]
        :type n: int
        :rtype: None Do not return anything, modify nums1 in-place instead.
        """
        p1=m-1  
        p2=n-1
        p=n+m-1
        while p2>=0:
            if p1>=0 and nums1[p1]>nums2[p2]:
                nums1[p]=nums1[p1]
                p1-=1
            else:
                nums1[p]=nums2[p2]
                p2-=1
            p-=1
        return nums1
```

## 📝 题目描述
> 用自己的话简要描述题目（不要直接复制原题）
给定一个数组和特定值val，将数组中不等于val的元素全部提前，最后输出不等于元素val的个数，要求在数组原地改动
---

## 💡 思路分析
- 核心思路：我的想法是，这一看就是双指针问题，我可以维护末端指针right，和起始指针left，当起始指针left小于等于right时循环结束，也就是尾端已放满val的值
- 关键难点：
- 是否参考题解：（否）

---

## 🔍 解法拆解
### 方法
- 时间复杂度：O(N)
- 空间复杂度：O（N）
- 关键步骤：
  1. 定义两个指针left，right，left为起始指针，right为末端指针=len(nums)-1
  2. 当起始指针left小于等于right时循环结束，途中不断判断当前指针（left）是否为val，若不为val则可以保留，left++
  3. 否则就将两个指针对应元素交换，并right-=1（这样设计，并用while控制循环能保证下次循环依旧是从left开始，避免了交换过去的也是val值）

---

## 🧾 代码实现

```Python
class Solution(object):
    def removeElement(self, nums, val):
        """
        :type nums: List[int]
        :type val: int
        :rtype: int
        """
        left = 0
        right =len(nums)-1
        while left <=right:
            if nums[left]!=val:
                left+=1
                continue
            nums[left],nums[right]=nums[right],nums[left]
            right -=1
        return left
```

```Python
class Solution(object):
    def removeDuplicates(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        slow =fast =1
        n=len(nums)
        if not nums:
            return 0
        while fast <n:
            #出现新元素
            if nums[fast]!=nums[fast-1]:
                nums[slow]=nums[fast]
                slow+=1
            fast+=1
        return slow
```

---

## 💡 思路分析
- 核心思路：
  使用双指针（快慢指针），在原数组上原地修改，通过控制写入位置来实现“最多保留两次”。

- 是否有多种解法：
  有：
  1. 使用计数变量（你的写法）
  2. 利用 `slow-k` 的通用双指针技巧（推荐写法）

- 关键难点：

  - 如何避免额外变量（优化思路）

## 🔍 解法拆解

### 方法一（推荐：slow-k 模板）
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- 关键步骤：
  1. 前两个元素直接保留
  2. 从第3个元素开始遍历（fast指针）
  3. 判断当前元素是否等于 `nums[slow-2]`
     - 如果不等 → 可以保留
     - 如果相等 → 跳过
  4. 更新 slow 指针

### 方法二（你的写法：计数法）
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- 关键步骤：
  1. 使用 `mark` 记录当前元素出现次数
  2. 如果遇到新元素 → 重置计数
  3. 如果重复次数 < 2 → 保留
  4. 否则跳过

---

## 🧾 代码实现

```python
# 方法一：推荐写法（slow-k 模板）
class Solution(object):
    def removeDuplicates(self, nums):
        if len(nums) <= 2:
            return len(nums)

        slow = 2
        for fast in range(2, len(nums)):
            if nums[fast] != nums[slow - 2]:
                nums[slow] = nums[fast]
                slow += 1

        return slow
```
```python
# 方法二：你的写法（计数法）
class Solution(object):
    def removeDuplicates(self, nums):
        slow = fast = 1
        n = len(nums)
        if not nums:
            return 0
        mark = 1
        while fast < n:
            if nums[fast] != nums[fast - 1]:
                nums[slow] = nums[fast]
                slow += 1
                mark = 1
            elif mark < 2:
                nums[slow] = nums[fast]
                slow += 1
                mark += 1
            fast += 1
        return slow
```

## 📝 题目描述
> 给定一个数组，找到出现次数超过一半的元素（一定存在）。

---

## 💡 思路分析
- 核心思路：
  找到数组中出现次数 > n/2 的元素。

- 是否有多种解法：
  有：
  1. 哈希表统计（你的写法）
  2. 排序取中位数
  3. Boyer-Moore 投票算法（最优解 ⭐）

- 关键难点：
  - 如何做到 O(1) 空间
  - 如何理解“投票抵消”的思想

- 是否参考题解：是（优化为投票算法）

---

## 🔍 解法拆解

### 方法一（你的写法：哈希表）
- 时间复杂度：O(n)
- 空间复杂度：O(n)
- 关键步骤：
  1. 用 Counter 统计每个元素出现次数
  2. 遍历字典
  3. 找到出现次数 > n/2 的元素

---

### 方法二（推荐：Boyer-Moore 投票算法 ⭐）
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- 关键步骤：
  1. 维护候选人 candidate 和计数 count
  2. count == 0 时，更新 candidate
  3. 相同则 +1，不同则 -1（相互抵消）//模型就是 众数+1 非众数-1 最后一轮一定能得到候选数 即candidate为所求
  4. 最终剩下的一定是多数元素

---

## 🧾 代码实现

```python
# 方法一：哈希表（你的写法）
class Solution(object):
    def majorityElement(self, nums):
        from collections import Counter
        d = Counter(nums)
        for k, v in d.items():
            if v > (len(nums) // 2):
                return k
```
```python
# 方法二：Boyer-Moore 投票算法（推荐）
class Solution(object):
    def majorityElement(self, nums):
        candidate = None
        count = 0

        for num in nums:
            if count == 0:
                candidate = num
            count += 1 if num == candidate else -1

        return candidate
```

### 方法（推荐：三次翻转 ⭐）
- 时间复杂度：O(n)
- 空间复杂度：O(1)

  2. 再翻转前 k 个
  3. 最后翻转剩余部分

---

## 🧾 代码实现

```python
class Solution(object):
    def rotate(self, nums, k):
        def reverse(left,right):
            while left < right:
                nums[left],nums[right]=nums[right],nums[left]
                left+=1
                right-=1
        n=len(nums)
        k%=n
        #整体翻转使得目标序列在前段序列之前
        reverse(0,n-1)
        #分别部分翻转回归原样
        reverse(0,k-1)
        reverse(k,n-1)
```

## 📝 题目描述
> 给定一个数组，表示每天的股票价格。你只能进行一次买入和一次卖出，求最大利润。

---

## 💡 思路分析
- 核心思路：
  在遍历过程中，记录历史最低价格，并在每一天尝试卖出计算最大利润。

- 是否有多种解法：
  有：
  1. 暴力枚举（O(n²)）
  2. 一次遍历（贪心 / DP）（推荐 ⭐）

- 关键难点：
  - 如何在一次遍历中同时维护“最低买入价”和“最大利润”
  - 如何避免未来数据影响过去决策

- 是否参考题解：否（已接近最优解）

---

## 🔍 解法拆解

### 方法一（推荐：贪心 / 一次遍历 ⭐）
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- 关键步骤：
  1. 初始化历史最低价格 `min_n`
  2. 遍历数组：
     - 计算当前卖出利润 `prices[i] - min_n`
     - 更新最大利润
     - 更新最低价格
  3. 返回最大利润（如果为负则返回 0）

---

## 🧾 代码实现

```python
# 你的写法（已是最优解）
class Solution(object):
    def maxProfit(self, prices):
        min_n = prices[0]
        max_n = -1

        for i in range(1, len(prices)):
            max_n = max(prices[i] - min_n, max_n)
            if min_n > prices[i]:
                min_n = prices[i]

        return max_n if max_n > 0 else 0
```

## 📝 题目描述
> 给定一个数组，每个位置表示最多可以跳跃的步数，判断是否能从起点跳到终点。

---

## 💡 思路分析
- 核心思路：
  维护当前能到达的最远位置 `farthest`，并在遍历过程中不断更新。

- 是否有多种解法：
  有：
  1. DFS / 回溯（超时）
  2. 动态规划
  3. 贪心（最优 ⭐）

- 关键难点：
  - 如何判断“是否可达”
  - 如何用一个变量表示全局可达范围

- 是否参考题解：否（标准贪心写法）

---

## 🔍 解法拆解

### 方法一（推荐：贪心 ⭐）
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- 关键步骤：
  1. 初始化 `farthest = 0`
  2. 遍历数组：
     - 如果当前下标 `i > farthest`，说明无法到达 → 返回 False
     - 更新最远可达位置 `farthest = max(farthest, i + nums[i])`
     - 如果 `farthest >= n - 1` → 提前返回 True
  3. 遍历结束仍可达 → 返回 True

---

## 🧾 代码实现

```python
class Solution:
    def canJump(self, nums):
        n = len(nums)
        farthest = 0

        for i in range(n):
            # 当前点不可达
            if i > farthest:
                return False

            # 更新最远可达距离
            farthest = max(farthest, i + nums[i])

            # 提前到达终点
            if farthest >= n - 1:
                return True

        return True
```

## 📝 题目描述
> 给定一个数组，每个位置表示最大跳跃长度，求从起点跳到终点的最少跳跃次数（保证一定可达）。

---

## 💡 思路分析
- 核心思路：
  使用贪心 + 分层扩展（类似 BFS 的层级思想），每次跳跃扩展当前能覆盖的最远区间。
  每一跳 = 覆盖一个区间
  在这个区间里，找下一跳能扩展到的最远位置

- 是否有多种解法：
  有：
  1. 动态规划（O(n²)）
  2. 贪心（最优 ⭐）

- 关键难点：
  - 如何理解“每一步跳跃 = 一层覆盖范围”
  - 如何用 `end` 控制跳跃次数
  - 如何避免重复计算路径

- 是否参考题解：否（标准贪心框架）

---

## 🔍 解法拆解

### 方法一（推荐：贪心 + 分层扩展 ⭐）
- 时间复杂度：O(n)
- 空间复杂度：O(1)
- 关键步骤：
  1. `farther`：当前能到达的最远位置
  2. `end`：当前这一跳的边界
  3. 遍历数组（到 n-2，因为最后一步不需要再跳）
  4. 更新 `farther = max(farther, i + nums[i])`
  5. 当 `i == end`：
     - 说明当前这一跳的范围用完
     - step + 1（跳一步）
     - 更新 end = farther

---

## 🧾 代码实现

```python
class Solution(object):
    def jump(self, nums):
        farther = 0
        end = 0
        step = 0
        n = len(nums)

        for i in range(n - 1):
            # 当前不可达（理论上不会发生，题目保证可达）
            if i > farther:
                return -1

            # 更新最远可达位置
            farther = max(farther, i + nums[i])

            # 当前层结束，必须跳一步
            if i == end:
                step += 1
                end = farther

        return step
```

## 📝 题目描述
> 给定股票每天价格，最多可以完成 2 笔交易（买+卖算一笔交易），求最大利润。

---

## 💡 思路分析
- 核心思路：
  用状态机表示“第几次交易 + 是否持有股票”，通过动态规划或记忆化搜索枚举所有状态转移。

- 是否有多种解法：
  有：
  1. DFS + 记忆化搜索（你的版本）
  2. 三维 DP（你的版本）
  3. 空间优化 DP（进阶 ⭐）

- 关键难点：
  - 如何定义“交易次数 k”
  - 如何区分“买入/卖出状态”
  - 如何正确设计状态转移
  - DFS 中如何避免重复计算

- 是否参考题解：部分参考（标准 DP 状态机模型）

---

## 🔍 解法拆解

---

### 方法一（推荐理解：DFS + 记忆化搜索 ⭐）
- 时间复杂度：O(n * k)
- 空间复杂度：O(n * k)

#### 状态定义：dfs(i, count, hold)

- i：当前天数
- count：剩余交易次数
- hold：是否持有股票（True / False）

---

#### 状态转移：

- 持有股票（hold=True）：
  - 继续持有
  - 或买入（消耗资金）

- 不持有股票（hold=False）：
  - 什么都不做
  - 或卖出（获得利润 + 交易次数 -1）

---

#### 关键逻辑：
- 买入不会减少 count
- 卖出才消耗一次交易次数

---

### 方法二（推荐：DP 三维状态 ⭐）
- 时间复杂度：O(n * k)
- 空间复杂度：O(n * k)

#### 状态定义：dp[i][j][0/1]

- i：前 i 天
- j：进行了 j 次交易
- 0：不持有股票
- 1：持有股票

---

## 🧾 代码实现

---

### 方法一：DFS + 记忆化搜索

```python
class Solution:
    def maxProfit(self, prices):
        n = len(prices)

        from functools import cache

        @cache
        def dfs(i, count, hold):
            if count < 0:
                return float('-inf')

            if i < 0:
                return 0 if not hold else float('-inf')

            if hold:
                return max(
                    dfs(i - 1, count, True),
                    dfs(i - 1, count, False) - prices[i]
                )
            else:
                return max(
                    dfs(i - 1, count, False),
                    dfs(i - 1, count - 1, True) + prices[i]
                )

        return dfs(n - 1, 2, False)
```
### 方法二：DP 三维
```python
class Solution(object):
    def maxProfit(self, prices):
        n = len(prices)
        k = 2

        dp = [[[float('-inf')] * 2 for _ in range(k + 2)] for _ in range(n + 1)]

        for i in range(1, k + 2):
            dp[0][i][0] = 0

        for i, p in enumerate(prices):
            for j in range(1, k + 2):
                # 不持有
                dp[i + 1][j][0] = max(
                    dp[i][j][0],
                    dp[i][j - 1][1] + p
                )

                # 持有
                dp[i + 1][j][1] = max(
                    dp[i][j][1],
                    dp[i][j][0] - p
                )

        return dp[n][k + 1][0]
```
